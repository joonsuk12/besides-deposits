# '쉽게 말하면' 요약 작성 지침

Claude(Claude Code 세션 또는 예약 작업)가 증권사 리포트를 주식 초보 눈높이로 다시 쓸 때 따르는 지침이다.
유료 API를 쓰지 않고, 사용자의 Claude 구독 안에서 Claude Code가 직접 쓴다.

## 순서

`backend` 폴더에서:

1. 요약할 리포트 내보내기 (관심 종목 먼저, 최근 3일, 최대 30건)
   ```
   .venv\Scripts\python -m app.report.easy_cli pending data/easy_pending.json --days 3 --limit 30
   ```
2. `data/easy_pending.json`을 읽고, 리포트마다 아래 규칙대로 요약을 써서 `data/easy_written.json`에 저장한다.
3. 저장하기
   ```
   .venv\Scripts\python -m app.report.easy_cli save data/easy_written.json
   ```
4. 남은 건이 있으면 1~3을 반복한다. 한 번에 30건 정도씩 나눠서 한다.

`data/` 폴더는 커밋하지 않는다.

## 받는 재료 (easy_pending.json의 한 건)

`nid`, `item_name`(종목), `broker`(증권사), `write_date`, `title`(리포트 제목), `opinion`(투자의견), `goal_price`(목표주가), `goal_change`(같은 증권사 직전 대비: 상향/하향/유지/처음/null), `text`(증권사가 쓴 요약문 평문)

## 쓰는 결과 (easy_written.json, 배열)

```json
[
  {
    "nid": "97942",
    "one_liner": "환율 때문에 이익이 덜 나와 보였지만, 본업인 전자 부품은 기대보다 잘 팔렸다는 리포트예요.",
    "story": "두산 전자BG(반도체 기판 소재 사업)의 3분기 매출이 시장 예상보다 많았어요. 다만 원화가 강해져 해외에서 번 돈을 원화로 바꾸면 줄어드는 효과 때문에 이익률이 낮아 보였어요. 대신증권은 그래도 목표주가를 조금 낮췄어요.",
    "watch_out": "목표주가를 낮췄다고 회사가 나빠졌다는 뜻은 아니에요. 증권사가 예상한 앞으로의 가격일 뿐이에요."
  }
]
```

| 항목 | 길이 | 내용 |
|---|---|---|
| `one_liner` | 60자 안팎, 최대 120자 | 이 리포트가 하려는 말 한 문장 |
| `story` | 2~3문장, 최대 600자 | 왜 그렇게 보는지. 어려운 말은 괄호로 풀어서 |
| `watch_out` | 1문장, 없으면 null | 초보가 오해하기 쉬운 점이나 리포트가 말한 위험 |

## 규칙

1. **말투**: 해요체. 친구에게 설명하듯 쉽게. 초등학생도 알아들을 단어를 고른다.
2. **용어**: 전문 용어는 쓰되 바로 뒤 괄호에 풀이를 단다. 예: "컨센서스(여러 증권사 예상의 평균)", "OPM(매출 중 본업으로 남긴 이익 비율)".
3. **사실만**: `text`에 있는 내용과 숫자만 쓴다. 없는 숫자·전망·이유를 지어내지 않는다. 확실하지 않으면 빼거나 "리포트는 ~라고 봐요"처럼 증권사의 의견임을 드러낸다.
4. **권유 금지**: "사세요/파세요/좋은 기회예요/지금이 매수 타이밍" 같은 표현을 절대 쓰지 않는다. 판단은 늘 "○○증권은 ~라고 봐요"처럼 증권사의 의견으로 전한다.
5. **목표주가**: 숫자를 쓸 때는 "증권사가 예상한 가격"임을 분명히 한다. 상향·하향은 `goal_change`를 그대로 따른다.
6. **투자의견이 없는 리포트**(산업 분석, 기업 탐방, IR 보고서): 회사가 무슨 일을 하고 리포트가 무엇에 주목했는지를 쓴다. 의견이 없다는 걸 굳이 쓰지 않는다.
7. **watch_out**: 다음 중 해당하는 것 하나. 리포트에 적힌 위험(환율, 경쟁, 비용 등) / 초보가 오해하기 쉬운 점(목표주가는 약속이 아님, 일회성 이익 등). 쓸 게 없으면 null.
8. **영어·숫자 표기**: 3Q26 → "2026년 3분기", YoY → "작년 같은 때보다", QoQ → "지난 분기보다"로 풀어 쓴다.
